Dovilo: die Aufgabenliste, aus der dein Coding-Agent arbeitet.

Claude Code, Cursor und jeder MCP-Client verbinden sich von jedem Rechner und sehen nur ihre eigenen KI-Aufgaben.

Dovilo holen MCP-Doku lesen

Kurz gesagt

Dovilo ist eine To-do-App mit einer eigenen Aufgabenliste für KI-Coding-Agenten. Agenten verbinden sich per MCP mit dovilo.app/mcp/agents: 9 Tools, kein Erstellen, kein Löschen, und deine persönliche Liste ist nie sichtbar. ChatGPT oder Claude können die Arbeit planen; jede Anweisung wartet auf deine Freigabe. Pro, $2.49 im Monat, 15 KI-Aufgaben im Monat.

So läuft eine KI-Aufgabe ab

  1. 01 Schreib die Aufgabe Oder lass ChatGPT oder Claude sie vorschlagen.
  2. 02 Gib sie am Smartphone frei Nichts erreicht einen Agenten, bevor du Ja sagst.
  3. 03 Dein Agent arbeitet sie ab Schritte und Notizen landen live in der Aufgabe.
  4. 04 Er fragt, du antwortest Er hält bei einer Entscheidung an; du antwortest vom Smartphone oder im Chat.

Anwendungsfall: Dovilo wird mit KI-Aufgaben gebaut

Dovilo wird genau so gebaut. Es hat fünf Projekte, Backend, Mobile, Desktop, Edge und Landing, und für jedes einen Agenten in Claude Code. Ich plane eine Änderung in Claude, und Claude schlägt KI-Aufgaben im passenden Projekt vor. Ich gebe sie auf meinem Smartphone frei; der Agent am Schreibtisch arbeitet sie ab, schreibt seine Schritte und Notizen in die Aufgabe und hält an, um zu fragen, wenn eine Entscheidung bei mir liegt. Diese Seite ist auf demselben Weg durch das Projekt Landing gegangen.

Funktioniert mit jedem MCP-Coding-Client

  • Claude Code, Cursor, Codex CLI, Gemini CLI, Windsurf und Claude Desktop arbeiten die Aufgaben ab.
  • LangGraph, CI-Jobs und jeder MCP-Client verbinden sich mit derselben URL und demselben Schlüssel.

Einen Coding-Agenten verbinden: eine URL und ein Schlüssel

Claude Code
claude mcp add --transport http --scope local dovilo https://dovilo.app/mcp/agents --header "Authorization: Bearer <API_KEY>"

Lege in der App einen Agenten an, kopiere seinen Schlüssel einmal und richte deinen Client auf https://dovilo.app/mcp/agents. Dovilo Desktop schreibt die Konfiguration für 7 Clients.

Ein Projekt trägt sein Briefing und seine Dokumente

Spezifikationen, Entscheidungen und Checklisten liegen im Projekt. Dein Coding-Agent liest sie mit read_context; der Agent eines Unterprojekts liest auch die seines übergeordneten Projekts.

  • Im Chat entworfen, auf dem Handy freigegeben. ChatGPT oder Claude schlägt ein Dokument oder eine Änderung vor.
  • Agenten lesen, schreiben nie. Kein Agent-Tool ändert ein Dokument.
  • Markdown, versioniert. Bis zu 200 KB pro Dokument und 50 pro Projekt; die letzten 5 Versionen bleiben erhalten.
  • Gelöscht wird nur in der App. Kein MCP hat ein Lösch-Tool, und ein gelöschtes Dokument ist endgültig weg.

Was dein Coding-Agent kann und was nicht

  • Ihre eigenen Aufgaben, sonst nichts.
  • Jede Aufgabe, die er bekommt, schreibt oder genehmigt ein Mensch.
  • Er kann keine Aufgaben anlegen oder löschen. Abbrechen lässt die Aufgabe sichtbar.
  • Deine Coding-Arbeit bleibt aus deiner Chat-App heraus, außer du schaltest es ein.
  • Widerrufe jeden Agent-Schlüssel sofort vom Handy aus.

Klare Antworten

Muss Dovilo Desktop laufen, damit mein Agent arbeitet?

Nein. Agenten verbinden sich direkt mit dovilo.app/mcp/agents. Desktop ist der Windows- und Mac-Client für KI-Aufgaben, Schlüssel, Briefings und Webhooks.

Was sieht der Agent?

Die KI-Aufgaben der Projekte, denen er zugewiesen ist, Briefing und Dokumente jedes Projekts, Briefing und Dokumente eines übergeordneten Projekts und deine Antworten. Deine persönliche To-do-Liste ist auf der Tool-Oberfläche gar nicht vorhanden.

Kann ein Agent eine Aufgabe löschen?

Nein. Auf keinem der beiden Server gibt es ein Lösch-Tool. Ein Agent kann eine Aufgabe mit Begründung abbrechen, und die Aufgabe bleibt sichtbar.

Läuft es auch in CI oder auf einem Server?

Ja. Dieselbe URL und derselbe Schlüssel funktionieren auf jedem Rechner. Ein Schlüssel pro Agent, am Smartphone widerrufbar.

Ich nutzte Desktop 1.8. Was ist anders?

Der lokale Server von 1.8 ist weg. Erstelle in der App einen Agenten, kopiere seinen Schlüssel und stell deinen Client auf die Remote-URL um. Schritte in der MCP-Doku.
