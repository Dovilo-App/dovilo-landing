Endpoints

The two servers share a host and nothing else. They take different credentials and reach different data, so a chat assistant never holds an agent's access, and an agent never holds yours.

Authentication

Agents authenticate with a key the user creates for them; assistants authenticate as the user, through a sign-in the user completes.

Agents MCP: one key per agent

  • Send the key on every request as Authorization: Bearer <key>.
  • The key is shown once. Dovilo stores only a hash of it.

Personal MCP: sign in with Dovilo

  • Access tokens expire after 1 hour and refresh tokens after 90 days.

Status values

An AI task moves through these values. The same values appear in webhook payloads.

Light, long (code-long)

AI integration prompt
- What should happen when an event arrives? (Slack notification?
  Linear sync? CI trigger? Database log? Hand off to an LLM?)
- Which stack should the receiver use? Match this project if obvious;
  otherwise ask. (Node/Express, FastAPI, Go net/http, Cloudflare
  Workers, Vercel function, etc.)
- Where will it be deployed and what's the public URL going to be?
  Public HTTPS URLs are delivered by Dovilo's server. A localhost URL
  is delivered by Dovilo Desktop, which must stay open. To test a
  public URL from a dev machine, suggest ngrok / cloudflared /
  tailscale funnel.

Route: POST /webhooks/dovilo  (or fit the project's conventions)

CRITICAL RULES:
- Read the RAW request body before any JSON parsing. The HMAC is
  computed over the raw bytes; re-serializing breaks the signature.
- Verify `X-Dovilo-Signature` (format: `t=<unix-ms>,v1=<hex>`):
    1. Parse `t` and `v1`.
    2. Reject if `|Date.now() - t|` > 5 minutes (replay protection).
    3. Compute `HMAC_SHA256(secret, `${t}.${rawBody}`)`, hex-encode.
    4. Compare to `v1` in CONSTANT TIME (timingSafeEqual /
       hmac.compare_digest / hmac.Equal). Never use plain `==`.
- Use `X-Dovilo-Delivery` (also `id` in the body) as the idempotency
  key, store it, drop duplicates. Same id is reused across retries.
- Respond 2xx on success and 401 on a bad signature. NEVER answer a
  bad signature with 410. Respond 410 ONLY if the integration is
  permanently dead: Dovilo disables the project's webhook when it
  sees 410.
- Read the signing secret from env var `DOVILO_WEBHOOK_SECRET`. Add
  a placeholder to `.env.example`. NEVER commit the real secret.

FAQ accordion

Each question an h3 inside a summary; the answer matches the page's FAQPage JSON-LD word for word. An answer may run to two paragraphs (the third question, open).

Light

Is Dovilo free?

Yes. Dovilo is free to download and use. The free tier includes full to-do management, unlimited tasks and categories, unlimited focus sessions (single and Pomodoro), basic city building, dark & light themes, and zero ads. Dovilo Pro adds planning with ChatGPT, Claude, Gemini or Grok, 15 AI tasks a month for coding agents, the desktop app for Windows and Mac, cloud sync, the Focus Ambience Pack, all buildings and advanced statistics.

Does Dovilo have ads?

No. Dovilo is completely ad-free, both in the free tier and in Pro. We believe ads break focus, which is the opposite of what a productivity app should do.

What are the pricing options?

Dovilo Pro is $2.49 a month, $19.99 a year or $49.99 once, with a 7-day trial in the app. All plans include the same Pro features.

There are also one-time purchases that are not subscriptions: the Focus Ambience Pack ($4.99: 5 scenes and 16 sound layers), the Full City Package ($4.99: every building, decoration and upgrade), and AI task packs from $0.99. Both packs are already included with Pro.

Is Dovilo free?

Yes. Dovilo is free to download and use. The free tier includes full to-do management, unlimited tasks and categories, unlimited focus sessions (single and Pomodoro), basic city building, dark & light themes, and zero ads. Dovilo Pro adds planning with ChatGPT, Claude, Gemini or Grok, 15 AI tasks a month for coding agents, the desktop app for Windows and Mac, cloud sync, the Focus Ambience Pack, all buildings and advanced statistics.

Does Dovilo have ads?

No. Dovilo is completely ad-free, both in the free tier and in Pro. We believe ads break focus, which is the opposite of what a productivity app should do.
