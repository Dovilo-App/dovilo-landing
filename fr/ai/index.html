Dovilo : la liste de tâches où travaille votre agent de code.

Claude Code, Cursor et tout client MCP se connectent depuis n'importe quelle machine et ne voient que leurs propres tâches IA.

Télécharger Dovilo Lire la documentation MCP

En bref

Dovilo est une app de tâches avec une liste séparée pour les agents de code IA. Les agents se connectent à dovilo.app/mcp/agents via MCP : 9 outils, pas de création, pas de suppression, et votre liste personnelle n'est jamais visible. ChatGPT ou Claude peuvent planifier le travail ; chaque instruction attend votre approbation. Pro, $2.49 par mois, 15 tâches IA par mois.

Comment ça marche

  1. 01 Écrivez la tâche Ou laissez ChatGPT ou Claude la proposer.
  2. 02 Approuvez-la sur votre téléphone Rien n'atteint un agent avant votre oui.
  3. 03 Votre agent s'en charge Étapes et notes arrivent sur la tâche pendant qu'elle tourne.
  4. 04 Il demande, vous répondez Il s'arrête sur une décision ; vous répondez depuis votre téléphone ou le chat.

Comment Dovilo lui-même est construit

Dovilo est construit ainsi. Il a cinq projets, Backend, Mobile, Desktop, Edge et Landing, et un agent Claude Code pour chacun. Je planifie un changement dans Claude, qui propose des tâches IA sous le bon projet. Je les approuve sur mon téléphone ; l'agent sur le poste de travail les traite, écrit ses étapes et ses notes sur la tâche, et s'arrête pour demander quand une décision me revient. Cette page est passée par le projet Landing de la même façon.

MCP standard, sans dépendance

  • ChatGPT, Claude, Gemini et Grok planifient le travail et vous l'envoient pour approbation.
  • Claude Code, Cursor, Codex CLI, Gemini CLI, Windsurf et Claude Desktop traitent les tâches.
  • LangGraph, les jobs CI et tout client MCP se connectent avec la même URL et la même clé.

Connectez votre app IA

ChatGPT, Claude, Gemini et Grok se connectent au Personal MCP de Dovilo, à l'adresse https://dovilo.app/mcp. Connectez-vous d'abord à Dovilo ; quand votre app IA vous demande de vous connecter, utilisez le même compte Google ou Apple. Dans l'app, Paramètres > IA > Apps IA connectées vous guide à travers les mêmes étapes.

ChatGPT
  1. Ouvrez chatgpt.com/plugins.
  2. Choisissez « + », puis « Add custom MCP server ».
  3. Nommez-le Dovilo et collez l'adresse.
  4. Connectez-vous avec votre compte Dovilo et approuvez l'écran de consentement.

Sur le web. La possibilité d'ajouter un serveur MCP personnalisé dépend de votre formule ChatGPT.

Claude
  1. Ouvrez Customize > Connectors.
  2. Choisissez « Add custom connector ».
  3. Nommez-le Dovilo et collez l'adresse.
  4. Choisissez « Connect », connectez-vous avec votre compte Dovilo et approuvez l'écran de consentement.

Sur claude.ai ou Claude Desktop ; il fonctionne ensuite aussi dans l'app mobile. La formule gratuite permet un connecteur personnalisé.

Gemini
  1. Ouvrez gemini.google.com > Settings > Connected Apps.
  2. Choisissez « Add a custom app ».
  3. Collez l'adresse, puis choisissez « Next ».
  4. Connectez-vous avec votre compte Dovilo et approuvez l'écran de consentement.

Sur l'app web Gemini. Google le propose aux comptes personnels aux États-Unis, à partir de 18 ans, avec « Keep Activity » activé.

Grok
  1. Ouvrez grok.com/connectors.
  2. Choisissez « New Connector », puis « Custom ».
  3. Collez l'adresse.
  4. Connectez-vous avec votre compte Dovilo et approuvez l'écran de consentement.

Puis demandez-lui un plan dans une nouvelle conversation, par exemple : « Planifie ma journée de demain dans Dovilo avec 3 petites tâches. » Le plan apparaît dans votre boîte IA ; vérifiez-le et approuvez-le. Se connecter et envoyer des plans est gratuit ; ajouter un plan à vos listes nécessite Pro.

Les noms de menu sont les libellés anglais de chaque app, relevés sur sa page d'aide le 20 octobre 2026 : ChatGPT, Claude, Gemini, Grok. Si un menu a changé de place, la page d'aide donne l'actuel.

Configurer : une URL et une clé

Claude Code
claude mcp add --transport http --scope local dovilo https://dovilo.app/mcp/agents --header "Authorization: Bearer <API_KEY>"

Dovilo Desktop écrit la configuration pour 7 clients. Rédigez ensuite un brief de projet et une tâche IA.

Ce que l'IA peut faire ou non

  • Ses propres tâches, rien d'autre.
  • L'IA propose. Vous approuvez.
  • Votre travail de code reste hors de votre app de chat, sauf si vous l'activez.
  • Aucun outil de suppression. Ni maintenant, ni plus tard.
  • Révoquez toute connexion depuis votre téléphone, instantanément.

Réponses directes

Mon agent a-t-il besoin que Dovilo Desktop soit ouvert ?

Non. Les agents se connectent directement à dovilo.app/mcp/agents. Desktop est le client Windows et Mac pour les tâches IA, les clés, les briefs et les webhooks.

Que voit l'agent ?

Les tâches IA des projets qui lui sont assignés, le brief de chaque projet et vos réponses. Votre liste de tâches personnelle est totalement absente de ses outils.

Un agent peut-il supprimer une tâche ?

Non. Aucun des deux serveurs n'a d'outil de suppression. Un agent peut annuler une tâche avec un motif, et la tâche reste visible.

Puis-je le faire tourner en CI ou sur un serveur ?

Oui. La même URL et la même clé fonctionnent depuis n'importe quelle machine. Une clé par agent, révocable depuis votre téléphone.

J'utilisais Desktop 1.8. Qu'est-ce qui a changé ?

Le serveur local de 1.8 n'existe plus. Créez un agent dans l'app, copiez sa clé et pointez votre client vers l'URL distante. Les étapes sont dans la documentation MCP.
