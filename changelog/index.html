Release notes

Dovilo is a gamified productivity app for iPhone, iPad, Android, Windows and Mac: a to-do list, focus sessions with full-screen ambience, and an isometric city built out of the work you actually finish. This page tracks every build that shipped — new features, redesigns and fixes — on all four platforms. Mobile and desktop carry separate version lines, so the numbers below are not meant to line up.

Each platform is tracked on its own below. Desktop builds are also tagged in the public releases repository; if a newer one is published there than the builds listed here, this page adds it when you open it, so it is never a version behind.

Mobile: iOS & Android

2.0.027 October 2026 on Android · iOS: no date yetLatest
  • Plan with your AI: connect ChatGPT, Claude, Gemini or Grok to Dovilo. Plans land in the AI inbox and go into your lists with one tap once you approve them. Sending a plan is free; approving needs Pro.
  • AI Agents: connect Claude Code, Cursor or any MCP client to https://dovilo.app/mcp/agents with a key you create in the app. Agents work through AI tasks (15 a month on Pro, top-ups from $0.99), which can be scheduled and repeated, and ask you from the task when they need a decision.
  • Connected AI apps: for each connection, read access, approval mode (Ask me first by default), visible lists and projects, AI task access, and revoke.
  • A new Pro list. Reminders stay free; Pro adds +6 build permits a day and a 30-minute snooze.
  • Fixes: sheet animations and the keyboard, the bottom bars, deleting a list from the top navigation, the add button's shadow, signing out now clears AI data, and iOS declares all five languages.

2.0 connects Dovilo to the AI you already use. A chat assistant plans with you and proposes; nothing reaches your lists until you approve it on your phone. A coding agent gets its own key and its own AI tasks, and works them from any machine, without Dovilo Desktop running. It reached Google Play on 27 October 2026; the App Store release follows and has no date yet.

1.2.09 September 2026
  • Game layer completely redesigned — every asset redrawn, with animations. The city feels alive now.

The game layer is the half of Dovilo that pays the work back: a finished task or focus session earns bricks, and bricks buy the houses, offices, parks and roads you place yourself on the isometric grid. This release redrew every one of those pieces and put them in motion, so the city reads as a place you are building rather than a progress bar with textures on it.

1.1.03 September 2026
  • Brand new Focus page: the whole flow was redesigned and rebuilt.
  • UI and UX improvements throughout the app.

Focus came out of that rebuild in three shapes: a single session, a Pomodoro cycle — 25 minutes of work, a 5 minute break, a longer one every 4 rounds — or a session bound to one specific task. The timer keeps counting while the app is in the background or the phone is locked, Do Not Disturb holds every other app off for the duration, and the scene you pick — Rainy City, Midnight, Dusk, Snow or Fog — fills the screen and brings its own sound, blended from up to three layers at a time.

1.0.016 May 2026
  • Initial release.

The first public build, on the App Store and Google Play: the to-do list, the focus timer and the city they feed, offline-first and free to start.

Desktop: Windows & Mac

Desktop runs on its own version line, which is why its numbers sit well ahead of mobile’s. It needs an active Pro subscription, which you start from the mobile app. Since 2.0 it no longer carries an MCP server: coding agents in Claude Code, Cursor, Claude Desktop, Windsurf, Codex CLI or Gemini CLI connect to Dovilo's server from any machine and work only the AI tasks you write for them, never your personal to-do list. Desktop is the desktop client for your lists and AI tasks, where you also create agent keys and set up each project's webhook.

2.0.227 October 2026Latest
  • Task details open over the list instead of squeezing it, for My Tasks and for AI tasks. The list stays clickable: pick another task and the panel switches; click outside or press Escape to close.
  • A large view for long text. Notes, AI task descriptions, context, notes from AI and project briefs open in a wide, scrollable view, and editable fields stay editable there.
  • When an AI task is waiting for you, the agent's latest note sits inside the "Waiting for your input" card, right where you answer, as in the mobile app.
  • "AI Agents" everywhere: the sidebar, settings and dialogs use the mobile app's names, in all five languages.
  • Fixes: a running AI task's lock banner now reads "Changes are locked while the task runs."; selecting an agent in the sidebar no longer resets My Tasks or squeezes the detail panel; copy cleanup in all five languages, including the window title.

Nothing changes in the MCP contract, agent keys or webhooks: agents set up for 2.0.0 or 2.0.1 keep working, and existing installs update on their own.

2.0.120 October 2026
  • Creating, regenerating and revoking an agent key works again; in 2.0.0, connecting a new AI stopped at the key step. Webhook signing secrets and test pings work again too.
  • After a key error, Done in the connect wizard closes it. The Claude Desktop preset writes Dovilo's server address.
  • "Connected AIs" is now Agents. Disconnect is now Delete agent: it stops the agent's key right away, and the tasks it is running go back to the queue. "Last seen" is shown in your language.
  • A list or project is deleted only from the trash icon in its List settings, and the confirmation says what happens to its tasks and AI tasks. AI Tasks no longer shows an empty list after the project you were viewing is deleted or hidden.
2.0.019 October 2026
  • AIs connect to Dovilo's remote MCP server with their own key. The desktop app no longer has to be running on the same machine.
  • The MCP server built into 1.8 is off. An AI still set up for it gets an error that explains the switch, and the app shows a banner asking you to reconnect it.
  • The connect wizard has presets for Claude Code, Codex CLI, Cursor, Cursor CLI, Windsurf, Gemini CLI, Claude Desktop and any other MCP client, and shows where each config goes.
  • AI tasks can start at a set time and repeat. The list is grouped by status, notes from AI render as Markdown, safely, and you can answer an agent's question from the task. Tasks you cancel and runs that were skipped show as Cancelled.
  • One List settings window per list or project, with its name, Show in AI Tasks, the brief and the webhook. Nothing is written until you press Save. List edits from two devices no longer overwrite each other.
  • Public webhook URLs are delivered by Dovilo's server, and a project whose webhook the server can't deliver is flagged.
  • A new design aligned with the mobile app. Spanish, French and German are fully translated. Dovilo can require a minimum desktop version and asks you to update before you sign in.

2.0 moves the agent connection off the desktop. A coding agent reaches its AI tasks through https://dovilo.app/mcp/agents with a key of its own, from a laptop, a server or a CI runner, and keeps working when Desktop is closed. Agents set up for 1.8 need the new URL and a new key; the MCP reference walks through it.

1.8.017 May 2026
  • Initial stable release.

Every desktop build before these is tagged in the releases repository.

On the roadmap

Not shipped yet, and listed here so it is a promise on the record rather than a maybe:

  • Data export — get your tasks and history out of Dovilo in an open format. Everything the app knows already sits on your device, and Pro syncs it between devices, but there is no way yet to hand that data to another tool. Export will write it out as a file you can read and keep, so walking away from Dovilo costs you nothing you made here.

It will appear above when it ships, in the release that carries it. It has no date: naming one before it is real would make the promise worth less.

How updates reach you

iPhone, iPad and Android — through the App Store and Google Play, like any other app. With automatic updates on they arrive on their own; otherwise they are waiting in the Updates list in the store.

Windows and Mac — Dovilo Desktop updates itself. It picks up each new build on its own, so there is no installer to fetch a second time. The downloads page is only for the first install.

Where else things change

The webhooks reference carries its own changelog for the payload contract, so an integration that depends on the schema has one place to watch. The MCP reference documents both MCP servers; since Dovilo 2.0 they run on Dovilo's server, not inside the desktop app.
